# Mission 04: Objectives

## By The End Of Today's Session, You Will Be Able To

### Git & GitHub
- [ ] Explain what a repository, commit, and remote are, in your own words
- [ ] Initialize a Git repository in your portfolio folder
- [ ] Stage and commit changes with a clear, meaningful commit message
- [ ] Create a repository on GitHub and push your local commits to it
- [ ] Look at your GitHub repository in a browser and recognize your own commit history

### Deployment
- [ ] Explain what "deploying" a website actually means (in plain terms: making it reachable at a public URL)
- [ ] Enable GitHub Pages on your repository
- [ ] Find and visit your own live URL
- [ ] Make one small change, push it, and see it appear live

### Flask (Introductory Only)
- [ ] Explain what a web server does, in one sentence
- [ ] Run a five-line Flask app on your own machine
- [ ] See your own "Hello World" response appear in a browser at `localhost`
- [ ] Understand — without necessarily doing it yet — that Flask is what will let your portfolio *respond* instead of just *display*

### Secure Coding (Conceptual)
- [ ] Name at least two things a professional developer never hardcodes into their code
- [ ] Explain, in your own words, why "never trust user input" matters
- [ ] Recognize why running a server in debug mode is fine locally but risky in production

## What's Deliberately Not Required Today

- **Converting your whole portfolio into a Flask app.** This is real, valuable work — it's homework precisely because it deserves unhurried attention, not because it's less important.
- **Writing any SQL injection or XSS exploit code.** Today's security content is a conversation and a "spot the problem" exercise, not hands-on exploit-writing.
- **Setting up a custom domain.** GitHub Pages gives you a working URL today; custom domains are a nice-to-have for later, not a today problem.
- **Resolving merge conflicts.** You won't hit one today if you're working solo in a single repo — this is a Mission-05-or-later concept if it comes up at all.
- **Memorizing Git commands.** You need `git init`, `git add`, `git commit`, `git remote add`, `git push` — that's the whole list for today. Everything else, look up when you need it.

## Self-Check

Before you call today done, you should be able to answer, without notes:

1. What's the difference between committing and pushing?
2. If your site is live on GitHub Pages, where does the content it's serving actually come from?
3. What did your five-line Flask app do differently from just opening an HTML file in your browser?
4. Name one thing you should never write directly into your code, and what you'd use instead.

If any of these feel shaky, that's exactly what the homework research links in `resources.md` are for.
