# Exercise 01: JavaScript Console Challenge
### ~10 minutes, folded into the concept intro

## Purpose

Your first working JavaScript. Small on purpose — the goal is to see your own code actually run, not to learn everything about variables and functions in one go.

## What You'll Do

Open `starter/script.js`, then link it to any HTML page (or just open `starter/console-test.html` directly, which already links it) and check the browser Console (DevTools → Console tab).

Print three things using `console.log()`:

1. Your name.
2. Your favourite technology (so far — even if it's just "HTML").
3. One career goal.

## Example Shape

```javascript
const myName = "Jane Doe";
const favouriteTech = "CSS Grid";
const careerGoal = "Get my first junior developer role";

console.log(myName);
console.log(favouriteTech);
console.log(careerGoal);
```

Don't copy this verbatim — use your own name and answers. The shape is the template.

## Requirements Checklist

- [ ] Three variables declared using `const` (or `let`, if you want to try that instead).
- [ ] Three `console.log()` statements, each printing one variable.
- [ ] You've actually opened DevTools and seen all three values appear in the Console tab — not just written the code.

## Why This Matters

`console.log()` is the single most-used debugging tool in web development. Getting comfortable checking the Console early means when something breaks later today (and it will), your first instinct is already "let me log it and see what's actually happening" instead of guessing.
