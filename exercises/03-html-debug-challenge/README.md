# Exercise 03: HTML Debug Challenge
### 15 minutes

## Purpose

A quick drill, not a deep debugging exercise — this is meant to fit in whatever's left of the mission challenge slot. Its job is to build the *habit* of reading HTML critically. A longer, harder debugging exercise comes back in a later mission.

## The Scenario

`broken.html` is a tiny page with a handful of common beginner mistakes. Find them and fix them — that's it.

## Your Task

1. Open `broken.html` in your browser and see how it actually renders.
2. Open it in your editor and read through it.
3. Fix what's wrong. Don't rewrite it from scratch — the content is fine, only the structure is broken.

## What To Look For

Three categories, one or two bugs each:

- **Missing closing tags** — something opened but never closed.
- **A broken link** — an `<a>` tag that doesn't actually go anywhere.
- **Missing `alt` text** — an image with no `alt` attribute at all.

## Self-Check

- [ ] The page renders the way the content suggests it should (no weirdly nested or missing sections).
- [ ] Every tag that opens also closes.
- [ ] The link has a real `href`.
- [ ] The image has meaningful `alt` text.

## Ran Out Of Time?

Totally fine — this is the first thing to drop if the session runs long. It's listed as optional homework catch-up if you don't get to it. A longer, multi-bug debugging exercise returns later in the bootcamp, so nothing here is a one-time-only skill check.
