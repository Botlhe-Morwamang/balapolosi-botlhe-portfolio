# Exercise 01: Developer Profile Card
### 15 minutes

## Purpose

This is your very first HTML — deliberately small. The goal is to get one clean, correct section working before you move to anything bigger.

## What You'll Build

A single `<section>` containing:

1. Your name.
2. Your title (e.g. "Frontend Developer" or "Aspiring Web Developer").
3. One short sentence of introduction.
4. A profile image (a placeholder is completely fine for today).
5. One link — GitHub, LinkedIn, or email.

That's it. Five things. Don't add more during the session — extra sections and polish are homework (see `after-session.md` in the mission root).

## Example Shape

```html
<section>
  <img src="profile.jpg" alt="DESCRIBE THE PHOTO HERE">
  <h1>Jane Doe</h1>
  <h2>Frontend Developer</h2>
  <p>I build websites that solve problems.</p>
  <a href="https://github.com/yourusername">GitHub</a>
</section>
```

Don't copy this verbatim — use your own name, title, and sentence. The shape is the template; the content is yours.

## Requirements Checklist

- [ ] One `<h1>` for your name.
- [ ] One `<h2>` for your title.
- [ ] One `<p>` for your intro sentence.
- [ ] One `<img>` with real, meaningful `alt` text (not `alt="image"`).
- [ ] One `<a>` with a real `href`.

## Where To Start

Open `starter/index.html` — it has the `<section>` shape already there with `<!-- TODO -->` markers. Fill it in.
